# Guillaume Maiano

Software engineer, systems architect, and independent game developer based in France.

## What I Build
- **Systems & Tooling:** I build lean, deterministic software in **C++** and **Rust** with minimal dependencies, standard-library rigor, and test-driven workflows. Projects include **Tally** (a cross-platform, Git-tracked Markdown task engine with an ephemeral SQLite read cache) and **Wrenchfall Engine** (a shared C++ game engine library targeting Linux and PC).
- **Independent Games:** Under **Flying Fortress Games (FFG)**, I am developing *The Beaumont Legacy*, grounding virtual worlds in physical craft—period tailoring, leatherworking, and original narrative music.
- **Linux & Web Infrastructure:** Daily Linux user (`deb` and Fedora systems) who favors portable flat files, reproducible builds, and zero-JavaScript static sites built with Hugo.

## Beyond Code
When I step away from the terminal, I work with tactile materials—pattern-making garments and hats from scratch, wet-molding and stitching vegetable-tanned leather, painting watercolors, baking, and assembling tabletop miniatures with my children.
